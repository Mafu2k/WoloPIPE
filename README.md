# Wolowsky Sp. z o.o.

Strona firmowa Wolowsky Sp. z o.o. — statyczny serwis prezentujący ofertę i usługi firmy.

## Technologie

- HTML5, CSS3
- JavaScript (animacje)

## Uruchomienie lokalne

Otwórz `index.html` w przeglądarce lub uruchom prosty serwer statyczny:

```bash
python -m http.server 8000
```
